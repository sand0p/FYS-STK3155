It looks like your Python is trying to import the standard library module bz2, but the runtime system library libbz2 is not available on your HPC nodes. This is common on clusters when the bzip2 module/library isn’t loaded or isn’t on your library path.

Here are a few ways to fix it, in order of “most HPC-friendly”:

1) Load the cluster’s bzip2 module (recommended)
- Check what modules exist:
  - module spider bzip2
  - module avail bzip2
- Load it (name may be bzip2 or BZip2 and often has a version, e.g., 1.0.8):
  - module load bzip2
  - or: module load BZip2/1.0.8-GCCcore-12.3.0
- After loading, start a fresh shell or reload your Python module/environment:
  - module purge
  - module load bzip2
  - module load Python/3.11.3-GCCcore-12.3.0
- Verify Python sees bz2:
  - python -c "import bz2, sys; print('bz2 OK, Python:', sys.version)"

If this works, add the module load line(s) to your job script before running your code.

2) If bzip2 is installed but not on LD_LIBRARY_PATH
- Find the library path:
  - module show bzip2
  - or locate libbz2.so: find /storage/software -name "libbz2.so*"
- Export the path before running:
  - export LD_LIBRARY_PATH=/path/to/bzip2/lib:$LD_LIBRARY_PATH
- Test again:
  - python -c "import bz2; print('bz2 OK')"

3) Use a Conda environment (self-contained)
- If you have micromamba/mamba/conda available:
  - micromamba create -n p311-bz2 -c conda-forge python=3.11
  - micromamba activate p311-bz2
  - python -c "import bz2; print('bz2 OK')"
- Install your project deps (torch, torchtext, torchdata) inside this env. Conda will include libbz2 automatically.

4) Build local bzip2 and point Python to it (last resort, no modules/conda)
- Build bzip2 in your home:
  - wget https://sourceware.org/pub/bzip2/bzip2-1.0.8.tar.gz
  - tar xzf bzip2-1.0.8.tar.gz && cd bzip2-1.0.8
  - make -f Makefile-libbz2_so
  - make
  - mkdir -p $HOME/.local/{bin,lib,include}
  - cp libbz2.so.* $HOME/.local/lib/
  - cp bzlib.h $HOME/.local/include/
- Then:
  - export LD_LIBRARY_PATH=$HOME/.local/lib:$LD_LIBRARY_PATH
  - python -c "import bz2; print('bz2 OK')"
